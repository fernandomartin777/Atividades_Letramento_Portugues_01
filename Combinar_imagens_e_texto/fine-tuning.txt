A pasta padrão ficou numa constante no topo do script (PASTA_PADRAO_IMAGENS), e há duas formas de usar outra pasta:

1. Pasta diferente para uma questão inteira: acrescente pastaImagens nela.

js
{
  titulo: "Questão 3: Objetos do Dia a Dia",
  pastaImagens: "../Outra_Pasta/",
  paresNome: [ ... ],
  ...
}

2. Pasta diferente para uma figura específica: escreva o caminho completo no lugar do nome.

js
{ img: "../Especial/bicicleta.png", text: "bicicleta" }

Vale qualquer caminho que comece com ./, ../, /, http://, https:// ou data:. Isso permite misturar pastas dentro da mesma questão: figuras com nome simples vão para a pasta da questão (ou a padrão) e as com caminho completo vão para onde você indicou.

Um nome com subpasta, como "animais/cobra.png", é buscado dentro da pasta da questão ou da pasta padrão. Se a pasta da questão for escrita sem a barra final, o código acrescenta a barra sozinho.

Se alguma imagem não carregar, o caminho que o navegador tentou aparece no console (F12) como “Imagem não encontrada”, o que ajuda a achar erros de digitação.

**1. Fonte maior nos cards de texto**
Ela fica no CSS, no bloco `.card.text-card`, na linha `font-size`:

```css
font-size: calc(clamp(1.5rem, 2.8vw, 2rem) * var(--escala, 1));
```

Os três valores do `clamp` são o tamanho mínimo, o proporcional à largura da tela e o máximo. Antes era `clamp(1.2rem, 2.2vw, 1.6rem)`, e agora o texto fica cerca de 25% maior (de até 25,6px para até 32px). Para aumentar ou diminuir, mude o mínimo (`1.5rem`) e o máximo (`2rem`). **2. Marcar letras com o clique**
