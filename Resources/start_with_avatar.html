Jogo educativo

Este jogo foi projetado para funcionar com uma imagem de uma pessoa em pé com fundo transparente em formatos como png.

Você pode pedir para sites de inteligência artificial transformarem uma foto sua em imagem com fundo transparente ou escolher um personagem que já vem pronto para isso.

Escolha uma imagem sua para iniciar a atividade.
